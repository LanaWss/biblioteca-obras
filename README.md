# biblioteca-obras

É uma aplicação de uso pessoal, para categoria e acompanhar suas obras, já que vemos de diversas fontes diferentes. Para não se esquecer e continuar acompanhando, de forma fácil vai salvar os dados de onde parou da obra que já viu.

Para gerar as chaves, rode este comando no terminal:
```bash
node gerar-vapid.js
```

|     Variável      |       Obrigatória        |
|-------------------|--------------------------|
| VAPID_PRIVATE_KEY |           Sim            |
| VAPID_PUBLIC_KEY  |           Sim            |
|       PORT        |    Não (padrão 3000)     |
|     NODE_ENV      | Não (padrão development) |
